# V9-P3：证据图谱、离线地图、告警分诊与案件工作区

更新日期：2026-07-25

## 已实现

### 03 实体图谱

- 实体和关系都保存为组织级密文记录，并强制关联至少一条有效证据。
- 关系起点、终点必须是同一组织内的有效实体；已删除或跨组织记录不能引用。
- `fact`、`source_claim`、`inference` 三种认知状态使用不同颜色和线型，
  不把来源声明或分析推断伪装为事实。
- 支持 1–120 小时时间窗口、播放回看、证据 ID 拖入和双向实体关系显示。
- 点击图谱节点或关系台账可直接打开对应证据卡与来源原文入口。

### 04 地理态势

- 使用随程序发布的本地 SVG 矢量底图，不向第三方地图服务发送位置或访问内容。
- 地理事件强制校验有限经纬度、ISO 8601 时间、认知状态和证据链。
- 事件可关联实体、告警和案件；服务层核验每个关联记录的组织、类型与删除状态。
- 支持事件、实体、告警、案件四层开关及 1–120 小时回放。
- 点击普通事件进入证据卡；案件关联事件直接打开对应案件工作区。

### 05 告警分诊

- 当前加密规则对真实新闻缓存执行匹配，命中后幂等归档证据并生成密文告警。
- 支持认领、静默、升级、关闭和转案件；告警卡显示严重度、状态、版本、
  规则、来源和证据数。
- 过期版本在产生案件前即被拒绝，避免并发操作留下孤立案件。
- 转案件复用幂等引用并完整复制证据链；移动端保留全部分诊动作。

### 06 案件工作区

- 案件保存来源告警、证据、假设、任务、时间线、结论、矛盾证据和置信度。
- 每条结论必须引用同组织内的有效证据；无引用结论无法保存。
- 更新使用期望版本，冲突不会静默覆盖；已签发案件不能直接改写。
- 告警转案件后，浏览器验收已完成带证据结论并从 V1 更新为 V2。

## 数据与安全边界

- 图谱、地理事件、告警和案件正文只以 AES-GCM 密文写入 V9 数据库。
- 本阶段没有向 Supabase、Railway、飞书或第三方地图服务发送正文、密钥或位置。
- 浏览器验收数据库和测试主密钥在验证完成后均已移入 Windows 回收站，
  可恢复；正式 EXE 的 `%LOCALAPPDATA%` 数据未被修改。

## 诚实边界

1. 当前图谱采用本地确定性布局，适合小中型案件视图；尚未实现大型图谱的
   聚类、WebGL 加速或交互式拖拽布局。
2. 离线底图是低精度世界轮廓，不提供道路、海底地形、行政边界精度或实时军事图层。
3. 告警只覆盖客户端当前持有的新闻缓存；客户端离线期间不能承诺全天候捕获。
4. 自动分诊和置信度只表达公开来源工作流状态，不能替代人工军事判断。
5. 手机端本阶段支持分诊、指派入口和状态查看，不承担复杂图谱编辑或案件建模。
