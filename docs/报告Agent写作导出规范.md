# 报告 Agent 写作与导出硬性规范

## 禁用涉密等级词

报告 Agent 面向公开源防务战略分析与市场化研究报告交付，所有生成、修订、预览与 Word 导出内容严禁出现以下涉密等级字眼：

- 秘密
- 机密
- 绝密

执行要求：

- 生成提示词必须明确禁止使用涉密等级标识。
- 保存草稿前必须净化上述字眼。
- Word 导出前必须再次净化上述字眼。
- 若导出文本仍包含上述字眼，导出前必须阻断。

## 长报告字数规则

- 客户提出“1万字”“一万字”“10000字”“不少于12000字”等要求时，Agent 必须解析为目标正文字数。
- 生成完整报告时必须按目标字数提高模型输出预算，不得继续使用默认短文本预算。
- 若目标为 10000 字，正文建议不少于 8500 字；低于阈值时不得导出为正式 Word。
- 若模型一次生成不足，系统应尝试按原框架扩写；仍不足时必须在校验结果中标记未达标。

## 论文格式规则

- Word 导出采用 DefenseTracker SOD/SOP 研究报告格式。
- A4 页面，上 3.7cm、下 3.5cm、左 2.8cm、右 2.6cm。
- 题名页、目录页、正文、附录分离。
- 标题层级必须清晰，正文首行缩进、两端对齐、1.5 倍行距。
- Markdown 表格必须转换为 Word 原生表格。
- 来源证据池必须导出为“附录A：来源索引”。
